# نص التسجيلات الصوتية لتطبيق بصير ران

**الطريقة الأسهل:** ولّد الجمل كلها مشكولة في أربعة أجزاء من `docs/voice/VOICE_PARAGRAPHS.md`، وأرسل الملفات، فتقطعها `tools/split_voice.py` إلى ملف لكل جملة.

أو سجّل كل جملة في ملف مستقل، وسمِّ الملف باسمه في العمود الأول، مثل `centered.mp3`.
ضع الملفات في المجلد `app/src/main/assets/voice/`، أو أرسلها لي لأضيفها.

- الصيغ المقبولة: mp3 أو ogg أو wav أو m4a.
- صوت واضح وهادئ، بلا موسيقى، وبسرعة كلام طبيعية أو أسرع قليلاً.
- جمل التوقف تُقال بنبرة حازمة.
- اترك أقل من نصف ثانية صمت في بداية الملف ونهايته.
- أي جملة بلا تسجيل يقرؤها صوت الهاتف تلقائياً.
- أسماء الأزرار عند الضغط عليها مرة واحدة، ونتائج الفحص، يقرؤها صوت الهاتف دائماً، فلا تحتاج تسجيلها.

## التوجيه

| اسم الملف | الجملة |
|---|---|
| `centered` | أنت تسير في منتصف المسار |
| `correct_right` | انحرف قليلاً إلى اليمين |
| `correct_left` | انحرف قليلاً إلى اليسار |
| `near_edge_right` | اقتربت من حدود المسار، اتجه إلى اليمين |
| `near_edge_left` | اقتربت من حدود المسار، اتجه إلى اليسار |
| `at_edge_stop` | أنت على حد المسار. توقف وتحقق |
| `curve_right` | المسار ينحني تدريجياً إلى اليمين |
| `curve_left` | المسار ينحني تدريجياً إلى اليسار |

## التحذيرات والتوقف

| اسم الملف | الجملة |
|---|---|
| `obstacle` | يوجد عائق محتمل أمامك. خفف سرعتك وتوقف للتحقق |
| `obstacle_near` | انتبه، يوجد جسم قريب من مسارك. خفف سرعتك |
| `head_level` | انتبه، عائق على مستوى الرأس أمامك. توقف وتحقق |
| `drop_ahead` | انتبه، قد يوجد درج نازل أو حفرة أمامك. توقف وتحقق |
| `path_unclear` | المسار غير واضح. خفف سرعتك |
| `edge_only` | أرى حداً واحداً فقط للمسار. خفف سرعتك |
| `edge_near_stop` | اقتربت من حد المسار ولا أرى الجهة الأخرى. توقف وتحقق |
| `cannot_verify_stop` | توقف، لم أتمكن من التحقق من المسار |
| `angle_stop` | تغيرت زاوية الهاتف. توقف وأعد المعايرة |
| `latency_slow` | النظام بطيء الآن. خفف سرعتك |
| `latency_stop` | النظام بطيء جداً. توقف في مكانك |

## الجلسة

| اسم الملف | الجملة |
|---|---|
| `check_start` | قف في منتصف المسار، والكاميرا إلى الأمام. أفحص المسار الآن |
| `guidance_started` | المسار واضح. بدأ التوجيه |
| `not_ready` | لم أتمكن من التحقق من المسار. لا تبدأ الجري |
| `session_paused` | تم إيقاف التوجيه مؤقتاً. توقف في مكانك |
| `session_resumed` | استؤنف التوجيه |
| `session_ended` | انتهت الجلسة |
| `hold_to_activate` | اضغط مطولاً للتشغيل |
| `haptics_unavailable` | الاهتزاز غير متاح في هذا الهاتف. سأعتمد على الصوت |

## الاستخدام الأول وتعلّم الاهتزاز

| اسم الملف | الجملة |
|---|---|
| `onboarding_intro` | مرحباً بك في بصير ران. قبل أول جري، تأكد من أربعة أمور |
| `onboarding_light` | أولاً: إضاءة كافية لرؤية المسار والعوائق |
| `onboarding_mount` | ثانياً: ثبّت الهاتف بإحكام على صدرك، والكاميرا الخلفية إلى الأمام |
| `onboarding_safe` | ثالثاً: أجرِ التجارب الأولى في مكان آمن تعرفه، ومع مرافق مؤهل |
| `onboarding_camera` | رابعاً: سيتحقق التطبيق قبل كل جري أن الكاميرا ترى المسار وأن التحليل سريع بما يكفي |
| `onboarding_stop` | إذا طلب منك التوقف، فتوقف فوراً |
| `training_intro` | تعرّف على أنماط الاهتزاز قبل الجري. اليسار نبضة واحدة، واليمين نبضتان. سأشرح كل نمط ثم أشغّله |
| `pattern_left` | نبضة قصيرة واحدة: صحّح قليلاً إلى اليسار |
| `pattern_right` | نبضتان قصيرتان: صحّح قليلاً إلى اليمين |
| `pattern_strength` | كلما زاد ابتعادك عن المسار صارت النبضات أقوى. هذه خفيفة، ثم متوسطة، ثم قوية |
| `pattern_bend_left` | نبضة طويلة هادئة: منعطف إلى اليسار قادم |
| `pattern_bend_right` | نبضتان طويلتان هادئتان: منعطف إلى اليمين قادم |
| `pattern_attention` | ثلاث نبضات سريعة قوية: عائق أو أمر يحتاج انتباهك فوراً |
| `pattern_stop` | اهتزاز طويل تتبعه نبضتان: توقف عن الجري فوراً |
| `pattern_confirm` | نبضة تأكيد خفيفة: اكتمل الفحص أو بدأت الجلسة |
| `pattern_on_path` | نقرة خفيفة جداً كل بضع ثوانٍ: أنت على المسار |
| `quiz_intro` | اختبار قصير: سأشغّل نمطاً، ثم اختر معناه بالضغط المطوّل |
| `quiz_correct` | صحيح |
| `quiz_wrong` | غير صحيح |
| `quiz_passed` | أحسنت، اجتزت اختبار الاهتزاز |
| `quiz_failed` | لم تجتز الاختبار بعد. تدرّب على الأنماط ثم أعد المحاولة |

## الطوارئ

| اسم الملف | الجملة |
|---|---|
| `sos_started` | بدأ إجراء الطوارئ |
| `sos_location_ready` | تم تحديد موقعك |
| `sos_no_location` | لم أتمكن من تحديد موقعك. ستُرسل الرسالة بدون موقع |
| `sos_no_network` | لا يوجد اتصال بالإنترنت. الرسالة النصية والاتصال يعتمدان على شبكة الجوال |
| `sos_message_opened` | فُتح تطبيق الرسائل. اضغط إرسال لتأكيد الرسالة |
| `sos_dial_opened` | فُتحت شاشة الاتصال. اضغط زر الاتصال |
| `sos_share_opened` | فُتحت مشاركة الموقع. اختر التطبيق ثم أرسل |
| `sos_no_contact` | لا توجد جهة اتصال للطوارئ. أضفها من الإعدادات |
| `sos_no_app` | لا يوجد تطبيق مناسب على هذا الهاتف لتنفيذ هذا الإجراء |
