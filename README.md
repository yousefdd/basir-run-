# بصير (Basir Run)

برنامج أندرويد يرشد العدّائين المكفوفين بالصوت، ليجروا وحدهم بأمان.

## ما يعمل في النسخة 0.1
- **تتبع الجري** بخدمة Fused Location Provider: المسافة ودقة الموقع، مع إعلان صوتي بالعربي كل 100 متر.
- **زر الطوارئ**: يفتح رسالة جاهزة فيها رابط موقعك على خرائط Google لرقم تحفظه.
- **اختبار الصوت الاتجاهي**: نغمة في الأذن اليسرى أو اليمنى. هذه هي الإشارة التي ستعيد العدّاء إلى منتصف الحارة عندما نضيف الكاميرا.
- **واجهة صوتية**: أزرار كبيرة، وكل تغيير يُنطق بصوت عربي ويقرأه TalkBack.

## تحميل البرنامج على جوالك
كل تعديل على الفرع `main` يبني ملف APK تلقائياً على خوادم GitHub، ثم ينشره في صفحة **Releases** باسم «أحدث نسخة تجريبية».

1. افتح صفحة المستودع من جوالك، ثم **Releases**، ثم حمّل `basir-run.apk`.
2. اسمح بالتثبيت من مصادر غير معروفة عندما يطلب الأندرويد ذلك.
3. للتجربة الأفضل استخدم سماعة، فالنغمات الاتجاهية تحتاج أذنين منفصلتين.

إذا لم يتكلم البرنامج بالعربي: الإعدادات ← تحويل النص إلى كلام ← ثبّت اللغة العربية.

## المراحل القادمة
1. خدمة تعمل في الخلفية (Foreground Service) ليستمر التتبع والشاشة مطفأة.
2. اكتشاف خطوط الحارة بالكاميرا، وتحويل الانحراف إلى نغمة يمين أو يسار.
3. كاشف العوائق أمام العدّاء.
4. الإرشاد في الحدائق والممرات (الإصدار الثاني).
