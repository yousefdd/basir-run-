# بصير (Basir Run)

برنامج أندرويد يرشد العدّائين المكفوفين بالصوت، ليجروا وحدهم بأمان.

## ما يعمل في النسخة 0.2
- **واجهة حديثة** بـ Jetpack Compose و Material 3: داكنة وعالية التباين، وأزرار كبيرة، ومصممة للعمل مع TalkBack.
- **تتبع في الخلفية**: خدمة أمامية (Foreground Service) تستمر والشاشة مطفأة، مع إشعار فيه المسافة والزمن وزر إنهاء.
- **تحديد الموقع بـ Fused Location Provider**، مع فلترة ترفض الإشارات الضعيفة وقفزات GPS واهتزاز الموقع في المكان.
- **أثناء الجري**: المسافة بخط ضخم، والزمن، والإيقاع لكل كيلومتر، واللفات على مضمار 400 متر، وجودة إشارة GPS.
- **إعلان صوتي واهتزاز** كل مسافة تختارها (100، 200، 400 متر، أو كيلومتر).
- **أزرار الإنهاء والطوارئ تعمل بالضغط المطوّل** حتى لا تُضغط بالخطأ.
- **سجل الجري** وملخص بعد كل جري.
- **اختبار الاتجاه**: نغمة في الأذن اليمنى أو اليسرى.

## تحميل البرنامج على جوالك
كل تعديل على الفرع `main` يبني ملف APK تلقائياً على خوادم GitHub، ثم ينشره في صفحة **Releases** باسم «أحدث نسخة تجريبية».

1. افتح صفحة المستودع من جوالك، ثم **Releases**، ثم حمّل `basir-run.apk`.
2. اسمح بالتثبيت من مصادر غير معروفة عندما يطلب الأندرويد ذلك.
3. للتجربة الأفضل استخدم سماعة، فالنغمات الاتجاهية تحتاج أذنين منفصلتين.

إذا لم يتكلم البرنامج بالعربي: الإعدادات ← تحويل النص إلى كلام ← ثبّت اللغة العربية.

## المراحل القادمة
1. اكتشاف خطوط الحارة بالكاميرا، وتحويل الانحراف إلى نغمة يمين أو يسار.
2. كاشف العوائق أمام العدّاء.
3. ربط حزام الاهتزاز «بصير لمس» عبر البلوتوث.
4. الإرشاد في الحدائق والممرات (الإصدار الثاني).
